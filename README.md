# Rooting

Web εφαρμογή (PWA) για iPhone που παίρνει πολλές διευθύνσεις και βρίσκει τη γρηγορότερη σειρά για να τις επισκεφτείς.

- Προσθήκη διευθύνσεων με αναζήτηση, επικόλληση λίστας ή παρατεταμένο πάτημα στον χάρτη
- Βελτιστοποίηση σειράς με πραγματικούς χρόνους οδήγησης (OSRM)
- Αφετηρία: τρέχουσα θέση ή διεύθυνση. Τέλος: οπουδήποτε, επιστροφή, ή συγκεκριμένο σημείο
- Πλοήγηση σε Apple Χάρτες / Google Maps / Waze, «Παραδόθηκε», σημειώσεις, τηλέφωνο, ώρες άφιξης
- Δουλεύει χωρίς App Store: Safari → Κοινοποίηση → «Προσθήκη στην οθόνη Αφετηρίας»

Δεν χρειάζεται build: είναι στατικά αρχεία (index.html, app.js, solver.js, style.css).
