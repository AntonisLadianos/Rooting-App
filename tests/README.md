# Δοκιμές

Όλα τα δεδομένα εδώ είναι **φανταστικά** — ποτέ πραγματικά στοιχεία πελατών.

- `node tests/run.js` — ανάγνωση καρτελών από screenshots (κείμενο → στάσεις), χωρίς browser.
- `node tests/e2e.js` — η εφαρμογή μέσα σε browser (Playwright), με ψεύτικο χάρτη/αναζήτηση/διαδρομές:
  αποτυχία με λόγο, πλοήγηση (επαναφορά, άφιξη, επόμενη στάση, στο πλάι), παρατεταμένο πάτημα,
  καρτέλα στάσης, Πρώτα/Τελευταία, αναζήτηση ολοκληρωμένων, χειροκίνητη στάση με είδος.

Τρέχουν και οι δύο πριν από κάθε νέα έκδοση.
